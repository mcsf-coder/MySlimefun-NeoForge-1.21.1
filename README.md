# My Slimefun (NeoForge 1.21.1)

A **NeoForge 1.21.1** port of the classic **Slimefun** plugin—featuring a 54-slot chest-style Guide GUI, XP research unlocks, multiblock machines, dusts, and alloys.

## 🚗 My Story — Why Anyone Can Contribute!
I am **not** an expert coder—I am a **Grab driver** with **0 prior experience** building Minecraft mods, working on an **old, laggy PC**. I built the working foundation of this mod step by step using **Google AI Mode**.

If I can get this started from scratch on a slow PC, **you can definitely do this too—and do it even better than me!**

## 🤝 Looking for Contributors!
We are looking for fellow modders, artists, and testers to help build and complete this mod together! The project is organized into modular parts so anyone can pick a category and build it independently:

### Modular Roadmap & Categories
- [x] **Core Guide & XP Research System** — 54-slot chest UI, search bar, 3x3 recipe viewer, and persistent player XP unlocks
- [x] **Resources (Phase 1)** — 9 basic dusts, 14 ingots/alloys, smelting recipes, Grind Stone, and Ore Washer
- [ ] **Basic Machines** — Smeltery, Armor Forge, Compressor, Pressure Chamber, and Automated Panning Machine
- [ ] **Tools** — Lumber Axe, Grappling Hook, Smelter's Pickaxe, Explosive Pickaxe, and Multi-Tools
- [ ] **Useful Items** — Slimefun Backpacks, Cooler, Portable Crafter, and Tape Measure
- [ ] **Weapons** — Soulbound Swords, Seismic Axe, and Elemental Staffs
- [ ] **Armor** — Slimefun Alloy Armor Sets, Hazmat Suit, and Jetpacks
- [ ] **Food** — Juicer, Custom Drinks, and Magical Foods
- [ ] **Magical Items** — Talismans, Magical Lumps, Ender Backpack, and Runes
- [ ] **Electricity & Machines** — Energy Regulator, Solar Generators, Bio/Coal Generators, Electric Furnace, and Electric Ore Crusher
- [ ] **Cargo Management** — Cargo Manager, Input/Output Nodes, and Item Filtering

## 🛠️ How to Contribute
1. **Fork** this repository on GitHub.
2. Open the project in **IntelliJ IDEA** (Minecraft `1.21.1`, NeoForge `21.1.x`, Java `21`).
3. Pick an unchecked category above, add your items/machines, and test with `runClient`.
4. Open a **Pull Request** describing what you built!
